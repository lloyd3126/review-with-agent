# Review with Agent

透過 PDF 註解與 Agent 對話，逐步檢視並改善文件。

把文件與參考資料帶進工作台，讓 Agent 指出值得討論的問題，並在 PDF 上框出對應位置。你可以依編號討論、說明原本的想法，再自行修改原稿，匯出 PDF 後重新檢視。

工作台提供文件閱讀、參考資料清單、問題定位與討論提示。請告訴 Agent 文件的用途、讀者與檢視重點，並提供相關要求或評分標準。Agent 會依目前文件及這次提供的參考資料提出問題。

下載的專案沒有預先放入文件、參考資料或討論紀錄，請按「上傳文件」開始。

## 第一次使用

1. 下載整個專案並解壓縮，保留資料夾內的檔案。
2. 在 Agent 中開啟這個專案資料夾。
3. 在對話輸入「開始」。
4. 等待 Agent 準備所需環境、檢查工作台，並在內建瀏覽器開啟頁面。

你不需要自行輸入安裝或啟動指令。專案中的 `AGENTS.md` 和 skills 會讓 Agent 知道如何帶你使用。

如果沒有看到頁面，請展開 App 的側邊欄，切換到內建瀏覽器。載入工作台時請保持網路連線。

## 上傳文件

1. 按工作台左上角「上傳文件」。
2. 選擇 PDF，文件名稱會自動使用檔名。
3. 按「上傳並開啟」，等待左側顯示文件。

主要文件僅支援 `.pdf`，每個檔案最多 30 MB。請先在原本的編輯工具中確認排版，再匯出 PDF，例如使用 Word 的匯出或另存為 PDF 功能。

上方的操作依序為「上傳文件」、文件下拉選單、「上傳新版」與「刪除文件」。沒有文件時，下拉選單會停用。上傳多份文件後，可以從選單切換，每份文件各自保存參考資料與討論紀錄。

## 提供參考資料

把評分規準、寫作要求、背景資料、課本頁面或其他相關檔案交給 Agent，並告訴它要加入哪份文件。參考資料不限 PDF，也可以使用 Word、圖片、文字或其他格式。

Agent 會將資料放入專案，工作台右側會自動顯示參考資料清單。你也可以請 Agent 新增整理筆記或補充文件。網站只顯示檔名清單。

例如：「請把這份寫作要求加入剛上傳文件的參考資料」，或「請把剛才確認的要求整理成一份參考文件」。這一步可以略過。

Agent 會依格式閱讀參考資料。PDF 以視覺方式閱讀，圖片直接查看，文字直接閱讀。若有無法讀取的格式，Agent 會說明。

## 請 Agent 檢視

在開啟這個專案的 Agent 對話中，說明要檢視的文件與重點。例如：

```text
請檢視剛上傳的文件，參考已加入的資料，指出值得討論的問題。
```

也可以提供更明確的方向：

```text
這是一份給新進同事閱讀的報告，請檢查論點是否有依據，以及讀者能否理解各段之間的關係。
```

上傳後的操作引導、重新檢視提示與「討論這個問題」都會帶上固定的文件識別碼。把提示貼回 Agent 對話即可定位文件，即使檔名相同也能區分，你不需要手動輸入標題或檔案路徑。單純說「開始」或「重開」只會開啟工作台，等你提出檢視需求後才開始分析。

上傳完成後，工作台也會提供一段可複製的操作引導提示。把它貼回 Agent 對話，可以先請 Agent 說明接下來如何使用。

## 依編號討論問題

Agent 會把問題放進右側註解區。每則問題都有固定編號，例如 `#001`。點選註解可以跳到 PDF 的對應位置，並持續框出範圍。

你可以直接在對話中引用編號，也可以按「討論這個問題」，把複製的提示貼回 Agent 對話。Agent 會先詢問你的想法，一次提出一個問題，等你回覆後再提供回饋。

想繼續查看其他問題時，可以按註解區底部的「更多建議」，把提示貼回 Agent 對話。Agent 會保留既有註解並延續編號，避免重複已提出或已處理的問題。若沒有其他值得提出的問題，會直接說明。尚無註解或討論紀錄時，這個按鈕會停用。

初次註解會指出觀察到的問題、理由與依據，並提出開放問題。你可以先解釋原本的設計，再一起檢查取捨。需要範例時，也可以明確提出。

你可以逐一討論，也可以一次回覆多個編號：

```text
#001 我原本考慮的是……
#002 我想先討論這個問題。
#003 請先保留，之後再看。
```

沒有註解時，右側會顯示「Agent 會在這裡提出值得討論的問題」。沒有選擇文件時，左側會顯示「選擇上傳的文件在此預覽」。

## 修改後重新檢視

確認討論方向後，請自行在原本的編輯工具中修改文件，再匯出 PDF，回到工作台按「上傳新版」。

「上傳文件」會建立另一份文件。「上傳新版」會替換目前選定的 PDF，保留文件名稱與參考資料，不保存被替換的舊 PDF。

每次更換成功都會清空註解、討論紀錄與框選位置，編號從 `#001` 重新開始。即使再次選擇相同的 PDF，也會執行相同清空。若 PDF 檢查失敗，原文件與註解會保留。

更換後，工作台會開啟「重新檢視文件」視窗，提供可複製的提示。請把提示貼回 Agent 對話，才會開始重新檢視。你也可以直接說：

> 請先以視覺方式閱讀目前 PDF，並依格式閱讀這份文件的參考資料，再重新檢視文件。文件用途與背景可以沿用，但不要預設先前的建議仍然成立。每個問題都須重新核對，只提出目前文件仍支持的問題，避免為了延續先前討論而重複舊建議。先指出問題與依據，再透過提問引導我討論，不直接提供解法。

這個提示會提醒 Agent 重新判斷，盡量避免受到過去建議影響。你可以沿用同一個對話，不需要刪除對話紀錄。

## 刪除文件

選擇文件後，按上方「刪除文件」。確認視窗會說明刪除範圍，並提供「複製刪除提示」。

刪除以 **整份上傳文件及其附屬資料** 為單位，包含 PDF、所有參考文件、註解與討論紀錄，其他文件會保留。

按下複製按鈕不會立即刪除。請把提示貼回 Agent 對話，授權 Agent 處理。Agent 會核對文件名稱與識別碼，再刪除指定文件，工作台會自動更新清單。

一般說「開始」、檢視文件或重開工作台，都不會授權刪除資料。

## 下次繼續與保存資料

再次用 Agent 開啟同一個專案資料夾，說「開始」或「重開」即可。原有文件、參考資料與目前文件的討論紀錄都會保留。

備份或搬移時，請保留整個專案資料夾。原稿也請自行保存，方便後續修改與匯出 PDF。

工作台會自動同步文件與註解。如果稍等後仍未看到更新，可以直接告訴 Agent「工作台沒有更新」，請它協助檢查。

## 畫面發生錯誤時

工作台無法連線、服務發生錯誤或找不到頁面時，會顯示錯誤畫面。按「複製錯誤訊息給 Agent」，把訊息貼回對話，請 Agent 協助修復。修復後按「重新載入」。

如果自動複製未成功，畫面會展開並選取訊息，請手動複製。若整個網頁都無法開啟，只看到瀏覽器的連線錯誤，直接回到 Agent 對話說「重開」即可。

## 關閉或從頭開始

只想結束這次使用時，說「關閉工作台」，原有進度會保留。

若要清空後重新開始，可以說「清空文件、恢復初始狀態並關閉工作台」。這會移除專案中的所有文件、參考資料與討論紀錄。之後說「開始」，就會開啟空白工作台。
